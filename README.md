# 🛍️ Sanky's Store

A modern full-stack e-commerce platform built with the **PERN stack**, featuring authentication, product management, shopping cart, sandbox payments, order tracking, and real-time customer support.

## Features

- 🛒 Product browsing, cart & quantity management
- 🔐 Google authentication with Clerk
- 💳 Polar Sandbox checkout & payment integration
- 📦 Order creation, history & detailed order tracking
- 💬 Real-time order-specific customer support chat
- 🖼️ Product image optimization with ImageKit
- 🗄️ PostgreSQL database with Neon
- 🔗 Webhook-based payment & user synchronization
- 📱 Responsive modern UI

## Tech Stack

**Frontend:** React, JavaScript, Tailwind CSS, DaisyUI, TanStack Query  
**Backend:** Node.js, Express.js, TypeScript, Drizzle ORM  
**Database:** PostgreSQL, Neon  
**Authentication:** Clerk  
**Payments:** Polar  
**Real-time Chat:** Stream  
**Images:** ImageKit  
**Tools:** Git, GitHub, Vite, ngrok
